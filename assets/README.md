# Vyntric Support assets

Generated by `npm run brand:assets` (see `scripts/render-brand-assets.mjs`).

| File | Size | Where to use it |
| --- | --- | --- |
| `png/vyntric-logo.png` | 1024x1024 | **Bot avatar** + server icon — this is what every embed uses as its icon |
| `png/vyntric-emblem.png` | 512x512 | Emblem only, transparent — overlays, thumbnails, watermarking |
| `png/vyntric-banner.png` | 1200x400 | Panel banner — upload it and set `BRAND_BANNER_URL` |
| `vyntric-emblem.svg` / `vyntric-logo.svg` / `vyntric-banner.svg` | vector | Print, merch, web, re-export at any size |

## How the branding is wired

1. Set `png/vyntric-logo.png` as the **bot avatar** in the Discord Developer Portal.
   On startup the bot reads its own avatar and uses it as the icon for every embed
   (author icon, footer icon, thumbnail) — change the avatar, all embeds follow.
2. Optional: host `png/vyntric-banner.png` anywhere public (GitHub raw, imgur, CDN) and
   put the URL in `.env` as `BRAND_BANNER_URL=...` to display it inside the ticket panel.
3. `BRAND_ICON_URL` can override the avatar icon if you prefer a hosted copy.

Palette used by the bot (see `src/lib/brand.ts`):

- primary crimson `#B1121F`
- accent `#E23A4E`
- gold `#F2C14E` (Claim Reward)
- rose `#D1435A` (Partnership)
- success `#2FBF71` · warning `#F0A32E` · danger `#C81E2E`
